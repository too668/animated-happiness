API 文档

YOO 提供完整的图片托管 REST API，支持上传图片、查询列表、删除对象。

POST /api/upload 核心接口

接口说明

上传图片到 EdgeOne Blob Storage，返回公开访问 URL。支持三种上传方式，自动保留原始文件扩展名。

上传方式一：multipart/form-data

curl -X POST "https://yooy.cc.cd/api/upload" \
  -F "file=@/path/to/image.png"

上传方式二：JSON + Base64

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "demo.png",
    "base64": "data:image/png;base64,iVBORw0KGgo..."
  }'

上传方式三：纯二进制流

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: image/png" \
  --data-binary @image.png

响应体

{
  "ok": true,
  "message": "Image uploaded to EdgeOne Blob Storage",
  "key": "images/2026-08-29/1724900000000-abc123-demo.png",
  "url": "https://yooy.cc.cd/images/2026-08-29/1724900000000-abc123-demo.png"
}
GET /api/list 列表接口

获取当前存储中所有图片对象列表，支持分页查询。

curl "https://yooy.cc.cd/api/list"
# 分页: curl "https://yooy.cc.cd/api/list?limit=20&cursor=xxx"

响应体

{
  "ok": true,
  "items": [
    {
      "key": "images/2026-08-29/1724900000000-abc123-demo.png",
      "url": "https://yooy.cc.cd/images/2026-08-29/1724900000000-abc123-demo.png",
      "size": 102400,
      "contentType": "image/png",
      "uploadedAt": "2026-08-29T12:00:00.000Z"
    }
  ],
  "total": 1,
  "hasMore": false
}
DELETE /api/delete 删除接口

根据 key 删除指定图片对象。key 格式：images/YYYY-MM-DD/timestamp-random-filename.ext

curl -X DELETE "https://yooy.cc.cd/api/delete?key=images/2026-08-29/1724900000000-demo.png"

响应体

{
  "ok": true,
  "message": "Deleted successfully",
  "key": "images/2026-08-29/1724900000000-demo.png"
}

错误响应 

{
  "ok": false,
  "error": "Missing file field in multipart/form-data"
}

常见错误：

  • Missing file field — 未提供文件
  • Invalid file type — 不支持的文件格式
  • File too large — 超过 10MB 限制
  • File not found — 删除时 key 不存在
