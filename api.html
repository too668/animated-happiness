API 文档

1. 上传接口

POST /api/upload

用于上传图片文件，返回图片访问 URL。

2. 请求示例

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: application/json" \
  --data '{
    "filename":"demo.png",
    "base64":"data:image/png;base64,..."
  }'

3. 参数说明

字段 类型 说明
filename string 可选，保存文件名
base64 string Base64 图片内容
file File multipart/form-data 上传文件

4. 成功返回

{
  "ok": true,
  "message": "Image uploaded to EdgeOne Blob Storage",
  "key": "images/2026-08-29/1724900000000-demo.png",
  "url": "https://.../images/2026-08-29/1724900000000-demo.png"
}

5. 扩展接口

GET /api/list
DELETE /api/delete?key=images/xxx.png

用于获取图片列表并删除对象，适合管理后台使用。
