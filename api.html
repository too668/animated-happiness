API 文档

YOO 提供完整的图片托管 REST API，支持上传图片、查询列表、删除对象。

POST /api/upload 核心接口

接口说明

上传图片到 EdgeOne Blob Storage，返回公开访问 URL。支持三种上传方式，自动保留原始文件扩展名。

上传方式一：multipart/form-data

curl -X POST "https://yooy.cc.cd/api/upload" \
  -F "file=@/path/to/image.png"

上传方式二：JSON + Base64

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: application/json" \
  -d '{"filename":"demo.png","base64":"data:image/png;base64,iVBORw0KGgo..."}'

上传方式三：纯二进制流

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: image/png" \
  --data-binary @image.png

响应体

{
  "ok": true,
  "message": "Image uploaded to EdgeOne Blob Storage",
  "key": "images/2026-08-30/1725000000000-abc123-demo.png",
  "url": "https://yooy.cc.cd/images/2026-08-30/1725000000000-abc123-demo.png"
}
GET /api/list 可选分页

接口说明

获取所有图片列表，支持分页参数。

请求参数

参数类型默认值说明
limitnumber50每页数量，最大 100
cursorstring-分页游标，上次返回的 nextCursor

示例请求

curl "https://yooy.cc.cd/api/list?limit=20"

响应体

{
  "ok": true,
  "items": [
    {
      "key": "images/2026-08-30/1725000000000-abc123.png",
      "url": "https://yooy.cc.cd/images/2026-08-30/1725000000000-abc123.png",
      "size": 102400,
      "contentType": "image/png",
      "uploadedAt": "2026-08-30T10:00:00.000Z"
    }
  ],
  "total": 1,
  "nextCursor": null,
  "hasMore": false
}
DELETE /api/delete 危险操作

接口说明

根据 key 删除图片，key 必须以 images/ 开头。

请求参数

参数类型必填说明
keystring是图片存储键，格式: images/日期/时间戳-随机-文件名.ext

示例请求

curl -X DELETE "https://yooy.cc.cd/api/delete?key=images%2F2026-08-30%2F1725000000000-abc123.png"

响应体

{
  "ok": true,
  "message": "Deleted successfully",
  "key": "images/2026-08-30/1725000000000-abc123.png"
}

注意事项

  • 所有接口均支持跨域 (CORS)，可直接在前端调用
  • 单次上传文件大小限制：10MB
  • 支持的图片格式：JPEG、PNG、GIF、WebP、SVG
  • URL 子链会自动保留原始文件扩展名（如 .jpg、.png）
  • 删除操作不可撤销，请谨慎操作
