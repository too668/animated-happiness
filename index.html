接口文档

POST /api/upload 上传接口

上传图片到 EdgeOne Blob Storage，返回公开访问 URL。

请求参数

字段类型说明
filenamestring可选，保存的文件名
base64stringBase64 编码的图片数据（含 data URI 前缀）
contentTypestring图片 MIME 类型，如 image/png
fileFilemultipart/form-data 文件字段

请求示例

// JSON + Base64
curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "demo.png",
    "base64": "data:image/png;base64,iVBORw0KGgo..."
  }'

// multipart/form-data
curl -X POST "https://yooy.cc.cd/api/upload" \
  -F "file=@image.png"

响应体

{
  "ok": true,
  "message": "Image uploaded to EdgeOne Blob Storage",
  "key": "images/2026-08-29/1724900000000-demo.png",
  "url": "https://yooy.cc.cd/images/2026-08-29/1724900000000-demo.png"
}
GET /api/list 列表接口

列出当前存储中的所有图片对象。

// 响应体
{
  "ok": true,
  "items": [
    {
      "key": "images/2026-08-29/1724900000000-demo.png",
      "url": "https://yooy.cc.cd/images/2026-08-29/1724900000000-demo.png",
      "size": 102400,
      "contentType": "image/png",
      "uploadedAt": "2026-08-29T12:00:00.000Z"
    }
  ]
}
DELETE /api/delete?key=images/xxx.png 删除接口

根据 key 删除指定图片对象。

curl -X DELETE "https://yooy.cc.cd/api/delete?key=images/2026-08-29/1724900000000-demo.png"
{
  "ok": true,
  "message": "Image deleted successfully"
}

代码示例

JavaScript (Fetch)

const file = document
  .querySelector('#upload')
  .files[0];

const formData = new FormData();
formData.append('file', file);

const res = await fetch(
  'https://yooy.cc.cd/api/upload',
  { method: 'POST', body: formData }
);

const result = await res.json();
if (result.ok) {
  console.log(result.url);
}

Python 示例

import requests

url = "https://yooy.cc.cd/api/upload"
with open("image.png", "rb") as f:
    r = requests.post(url, files={"file": f})

print(r.json()["url"])
