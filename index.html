图片托管

基于 EdgeOne Makers + Blob Storage 构建的轻量级图片托管服务。
支持拖拽上传、批量管理、一键复制，返回可直链访问的公开 URL。

进入管理后台 查看 API 文档

功能特性

边缘节点出图

图片由 EdgeOne 边缘函数吐出，响应缓存 1 小时。实测 2.39MB 原图返回逐字节完整。

无需自建存储

文件存在 EdgeOne Blob Storage，函数内自动鉴权，不需要配置任何 token。配额为总量 1GB、单文件 25MB。

链接形态

形如 /i/2026/08/<随机>-<原名>.png，保留原始文件名便于辨认。注意它是函数路由而非静态文件，换图必须换链接。

两条上传路径

原图直传（任意格式，≤20MB，字节不经过函数）与压缩中转（仅图片，≤950KB，一条 curl 就能传）。

快速开始

Step 1：上传图片

拖拽文件到管理后台。默认走「原图直传」，任意格式、保留原图；也可切到「压缩中转」，只收图片、超过 950KB 会自动压。

去上传

Step 2：获取图片链接

上传成功后，点「新标签页打开」预览，或点「复制链接」拿到可直接分享的地址。

https://yooy.cc.cd/i/2026/08/6f20444f3562-demo.png

Step 3：调用 API

用 HTTP 接口上传图片，响应里的 url 就是图片链接。完整接口清单见 API 文档页。

curl -X PUT "https://yooy.cc.cd/api/upload?name=demo.png" \
  -H "Content-Type: image/png" \
  --data-binary @demo.png
