图床 API 文档

这是一个基于 EdgeOne Makers + Blob Storage 的图片上传与管理接口，适合对外提供图床服务，支持上传图片、返回 URL、查询列表、删除对象等操作。

功能概览

  • 上传图片并返回公开访问地址
  • 支持 Base64 和 multipart/form-data
  • 支持列表查看和删除对象
  • 适合前端页面、AI 调用和小型图床服务

基础地址

https://yooy.cc.cd

当前站点域名已配置为 yooy.cc.cd。

接口说明

1. 上传图片

POST /api/upload

上传图片并返回图片 URL 地址。

2. 获取图片列表

GET /api/list

返回当前存储中的图片列表，包含 key、URL、文件名等信息。

3. 删除图片

DELETE /api/delete?key=images/2026-08-29/demo.png

根据 key 删除指定图片对象。

4. 请求参数

字段 类型 说明
filename string 可选，上传时指定文件名
base64 string 图片的 Base64 字符串
file File multipart 表单文件字段

5. 成功响应

{
  "ok": true,
  "message": "Image uploaded to EdgeOne Blob Storage",
  "key": "images/2026-08-29/1724900000000-demo.png",
  "url": "https://example.com/images/2026-08-29/1724900000000-demo.png"
}

6. 错误响应

{
  "ok": false,
  "error": "Missing file field in multipart/form-data"
}

示例代码

cURL 示例

curl -X POST "https://yooy.cc.cd/api/upload" \
  -H "Content-Type: application/json" \
  --data '{
    "filename":"demo.png",
    "base64":"data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAAB..."
  }'

JavaScript 示例

const file = document.querySelector('#image').files[0];
const form = new FormData();
form.append('file', file);

const res = await fetch('https://yooy.cc.cd/api/upload', {
  method: 'POST',
  body: form
});

const result = await res.json();
console.log(result.url);

AI / 工具调用建议

POST https://yooy.cc.cd/api/upload
Content-Type: multipart/form-data

file=@image.png

该接口最适合给 AI、脚本、自动化工具调用，用来在不依赖本地文件系统的情况下直接上传图片并获取 URL。
