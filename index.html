私有云盘

基于 EdgeOne Makers + S3 / Blob 构建的高性能私有网盘。
支持最大 5GB~10GB 磁盘无损原件直传、多级目录树，支持将网盘文件夹直接映射为手机图册无损预览。

核心特性

边缘极速分发

文件经 EdgeOne 全球边缘节点输出，支持任意格式文件下载、预览与 HTTP 304 缓存协商。

双模存储引擎

支持 EdgeOne Blob 原生存储与 iDrive e2 S3 外部对象存储，支持单文件最大 5GB，不限格式。

完整文件管理

内置树状多级目录、右键菜单、文件重命名、批量移动、批量删除、分类相册与媒体灯箱。

安全私有隔离

配备管理员密码门禁、防暴力破解限流与细粒度 API Key 鉴权体系，保障私有数据安全。

快速使用

Step 1：上传文件

进入上传管理页面或文件浏览器，拖拽任意文件（文档、压缩包、音视频、软件等）直接上传。默认走原文件直传，保留原文件字节，最大支持 5GB。

进入上传

Step 2：文件管理与分享

进入文件管理器，可新建文件夹进行归档，支持一键复制公开直链、Markdown 格式或直接下载原文件。

文件管理器

Step 3：一键转为手机图册

在网盘任意图片文件夹点击「在图册中浏览」或「设为图册」，即可秒变类似手机相册的瀑布流媒体库，享受无损全屏沉浸式预览与手势切换。
