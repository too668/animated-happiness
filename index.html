YOO 图片托管

基于 EdgeOne Makers + Blob Storage 构建的轻量级图片托管服务。
支持拖拽上传、批量管理、一键复制，返回可直链访问的公开 URL。

进入管理后台 查看 API 文档

功能特性

边缘加速

基于 EdgeOne 边缘网络，图片全球加速访问，低延迟高可用。

安全可靠

文件存储在 EdgeOne Blob Storage，自动 CDN 分发，数据持久可靠。

URL 子链

上传时自动保留原始文件扩展名，生成的 URL 直接指向图片文件。

多种上传

支持 multipart/form-data、Base64 JSON、二进制流三种上传方式。

快速开始

Step 1：上传图片

拖拽图片到管理后台，或点击选择文件。支持 PNG、JPG、GIF、WebP 格式。

去上传

Step 2：获取图片 URL

上传成功后，点击「查看」在新标签页打开图片，或点击「复制」获取直链 URL。

https://yooy.cc.cd/images/2026-08-30/1725000000000-abc123-myimage.png

Step 3：使用 API

通过 HTTP API programmatically 上传图片，返回 JSON 响应包含公开访问 URL。

curl -X POST "https://yooy.cc.cd/api/upload" \
  -F "file=@photo.jpg"
